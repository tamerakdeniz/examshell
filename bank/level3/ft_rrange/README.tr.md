## Konu

```text
Soru adı: ft_rrange
Beklenen dosyalar: ft_rrange.c
İzin verilen fonksiyonlar: malloc
------------------------------------------------------------------------

malloc ile bir tamsayı dizisi ayır. Diziyi end değerinden start değerine kadar ardışık sayılarla doldur. İki uç da dahildir. Dizinin ilk elemanına işaretçiyi döndür.

Örnekler
(1, 3) → [3, 2, 1]
(-1, 2) → [2, 1, 0, -1]
(0, 0) → [0]
(0, -3) → [-3, -2, -1, 0]

Fonksiyon bildirimi
int     *ft_rrange(int start, int end);
```
