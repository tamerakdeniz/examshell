## Konu

```text
Soru adı: lcm
Beklenen dosyalar: lcm.c
İzin verilen fonksiyonlar:
------------------------------------------------------------------------

İki unsigned int parametresinin EKOK değerini hesaplayıp döndür. EKOK, sıfır olmayan iki sayıya da bölünebilen en küçük pozitif tamsayıdır. Sıfır dışında ortak bir kat bulana kadar katlarını hesaplayabilir veya EKOK(x, y) = |x * y| / EBOB(x, y) formülünü kullanabilirsin. |x * y| çarpımın mutlak değeridir. Sayılardan en az biri 0 ise sonuç 0’dır.

Fonksiyon bildirimi
unsigned int    lcm(unsigned int a, unsigned int b);
```
